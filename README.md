# ВКонтакте-бот ортоцентра «Авиценна» (Выборг)

Готовый к запуску бот сообщества ВКонтакте с услугами, ассортиментом,
адресами салонов, информацией о враче и записью на приём.

Написан на Python с использованием библиотеки `vk_api` и Bots Long Poll API.
База знаний — реальные данные сайта https://avicenna-vbg.ru/ (услуги и цены,
адреса и график салонов, карточка врача-ортопеда, группы товаров); данные
хранятся в Python-структурах (`data/*.py`), сторонние базы данных
не используются.

## Требования

- Python 3.11+;
- токен сообщества ВКонтакте с правами на работу с сообщениями;
- включенное «Сообщение сообщества» и Bots Long Poll API.

## Установка

### 1. Создайте файл `.env`

Скопируйте пример конфигурации:

```bash
# Linux / macOS
cp .env.example .env

# Windows
copy .env.example .env
```

Откройте `.env` и укажите токен сообщества:

```env
VK_GROUP_TOKEN=ваш_токен_сообщества
# Необязательно: укажите, если автоматическое получение group_id не сработает
# VK_GROUP_ID=123456789
```

Токен находится в управлении сообщества: **Работа с API → Ключи доступа**.
Файл `.env` добавлен в `.gitignore` и не должен попадать в репозиторий.

ID сообщества бот определяет автоматически. Если автоматическое определение
не работает, раскомментируйте `VK_GROUP_ID` и укажите ID вручную.

### 2. Создайте виртуальное окружение `.venv`

Linux/macOS:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

Windows PowerShell:

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

Windows CMD:

```cmd
python -m venv .venv
.venv\Scripts\activate.bat
pip install -r requirements.txt
```

## Запуск бота

```bash
python bot.py
```

В логе появится сообщение о запуске Long Poll. Для остановки нажмите
`Ctrl+C`.

Лог пишется и в консоль, и в файл `bot.log` (кодировка UTF-8, размер
ограничен 1 МБ, старые копии — `bot.log.1` и т. д.). В файле видно полный
цикл обработки: входящее сообщение → отправленный ответ (`Ответ отправлен
peer_id=..., message_id=...`) → все ошибки. Это удобно, когда нужно
проверить работу бота, а консоль недоступна.

При временных сетевых сбоях бот повторяет запрос Long Poll с тем же `ts`
и не переподключается заново — иначе накопленные на сервере ВКонтакте
события терялись бы и часть сообщений оставалась бы без ответа.

## Настройка сообщества ВКонтакте

1. Включите сообщения сообщества:
   **Управление сообществом → Сообщения → Сообщения сообщества → Включить**.
2. Создайте токен с правами на работу с сообщениями:
   **Управление сообществом → Работа с API → Ключи доступа → Создать ключ**,
   отметьте права **Сообщения сообщества**.
3. Включите Long Poll API:
   **Управление сообществом → Работа с API → Long Poll API → Включить**.
4. При необходимости укажите версию событий (достаточно настроек по умолчанию).

## Возможности бота

- главное меню: **Услуги**, **Ассортимент**, **Салоны и адреса**,
  **Врач-ортопед**, **О центре**;
- список услуг с кнопками выбора и подробной карточкой каждой услуги:
  описание, что входит, цена, показания;
- ассортимент: 12 товарных разделов салонов и описание каждого раздела;
- адреса, телефоны и график работы всех точек продаж (салон «Авиценна»
  на бульваре Кутузова, 9, на Ленинградском шоссе, 57, на улице Куйбышева, 9
  и магазин «Обувь Орто») с кнопками-ссылками на Яндекс.Карты;
- карточка врача-ортопеда (Левдиков А. В.): специальность, лицензия,
  телефон, почта, адрес кабинета;
- кнопка **Записаться к врачу**: инструкция по записи плюс кнопки-ссылки
  в сообщения сообщества и на страницу врача на сайте;
- обработка команд `старт`, `начать`, `/start` и неизвестных сообщений.

Все данные собраны со страниц сайта avicenna-vbg.ru; актуальность можно
проверить, сравнив модули `data/` с сайтом.

## Проверка без запуска бота

Смоук-тест прогоняет все payload- и текстовые команды через роутер,
проверяет длину подписей кнопок (лимит ВКонтакте — 40 символов)
и валидность JSON клавиатур:

```powershell
.venv\Scripts\python.exe smoke_check.py
```
